When you create a branch, its best to have a descriptive name. Usually, developers sort name their branches based on categories.

bugfix/bug-i-want-to-fix
feature/feature-i-want-to-implement

That way everyone knows what it is you're talking about


| Category     | Meaning                                         |
| ------------ | ----------------------------------------------- |
| feature/feat | a new feature you want to add                   |
| bugfix/fix   | a bug fix that is not urgent                    |
| hotfix       | a bug fix that is urgent                        |
| chore        | dependencies and docs                           |
| refactor     | reformatting the code without changing function |


[More on branch conventions](https://conventional-branch.github.io/)
