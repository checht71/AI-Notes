Readmes are important because they're the first (and sometimes only) thing that someone is going to look at when they check out your repo on GitHub. You should have one, but it should not be a giant novel. It should be a quick summary of what this program does.

# Outline:
Title
Subtitle -  a little more about your project
Intro paragraph - brief overview with keywords
Visual helper - diagram or video that demonstrates the program
Install instructions - how to run the program
How to work on the project - for contributors
Known issues - so people don't blow up your inbox
Donate link - If you're broke lol (me)


Other advice:
- Use keywords if you want your readme to be popular. That way it shows up on google searches
- Keep your readme up to date!!
