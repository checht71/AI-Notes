> [!tip] GitHub Pages turns any GitHub repository into a website
> takes HTML, CSS, and JavaScript files straight from a repository on GitHub, optionally runs the files through a build process, and publishes a website.

You can use GitHub pages to build your own portfolio website or to document your code!
