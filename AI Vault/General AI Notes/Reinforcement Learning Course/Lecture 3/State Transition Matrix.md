$\vec P$ = State Transition Matrix

if we sum up any row of a matrix, it should equal 1.
We fill the state transition matrix with probabilities. Each row is the current state, each column is the next state. Each element is $P(\text{column|row})$.
In other words, its the probability that the state in that row will yield the state in that column.

So for instance, the probability that it is rainy today and sunny tomorrow is $20 \%$.
